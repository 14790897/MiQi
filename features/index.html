    功能总览¶

    MiqroForge 是一个本地优先的个人 AI 助手桌面应用，将强大的 AI Agent 引擎与现代化的 Electron 桌面界面相结合。以下按功能域分类介绍 MiqroForge 当前实际提供的功能。

    🤖 AI 智能对话¶

    能力 说明
    自然语言对话 与 AI 进行多轮对话，支持流式响应、打字机动画效果
    工具调用可视化 实时显示 Agent 正在调用的工具及其参数、执行结果，命令输出内联展示
    中断与恢复 随时中止 Agent 执行；中断后可从断点一键继续，存在多条历史对话时可选从哪条恢复
    子代理结果 分工执行的子代理（subagent）结果以独立样式展示
    确认卡 任务执行过程中，AI 可以反过来向你提问或请求确认（文本或选项）
    Markdown 渲染 对话内容支持完整的 Markdown 渲染（表格、代码块、任务列表）
    代码高亮 180+ 编程语言的语法高亮
    推理块 AI 推理过程折叠展示，可开关推理模式
    Diff 视图 文件编辑操作以 diff 对比形式展示变更，可逐条回滚或接受
    文档预览 生成的 Word、表格、网页文件可在聊天内直接预览
    文件附件 支持上传图片（拖拽/粘贴）、文档等文件，Agent 可解析并理解内容

    📄 办公文档处理¶

    通过自然语言指令即可完成 Office 文档的读写操作，无需手动打开软件。

    Word 文档 (.docx)¶

    • 读取：提取 Word 文档中的文本内容、表格数据
    • 创建：支持结构化内容（标题、段落、表格、图片）和 Markdown 风格文本输入
    • 编辑：全文文本替换（段落 + 表格）、追加段落
    • 中文排版：内置 chinese_document 预设（标题黑体三号加粗居中，正文宋体小四 1.5 倍行距）
    • 自然语言格式：直接说"正文宋体小四，标题黑体加粗三号字居中"即可生效

    PowerPoint 演示文稿 (.pptx)¶

    • 读取：提取幻灯片文本、演讲者备注、表格数据
    • 创建：多张幻灯片，每张支持标题、副标题、正文、项目符号、图片
    • 图片定位：可精确控制幻灯片中图片的位置和尺寸

    Excel 电子表格 (.xlsx)¶

    • 读取：按工作表名称读取数据
    • 创建：多工作表工作簿，支持公式（以 = 开头自动识别）、内嵌图表（条形图、折线图、饼图）
    • 追加：向已有工作表追加数据行

    PDF 文档 (.pdf)¶

    • 读取：三层提取——快速提取 → 备用解析 → OCR 扫描件识别（支持中英文混排）
    • 创建：支持标题、各级标题、正文段落、表格（含表头）、列表、分页符
    • 中文字体：自动发现系统中的 CJK 字体，覆盖 Linux/WSL/Windows 路径
    • 样式预设：chinese_document、chinese_essay、report
    • 页面规格：支持 A4/Letter/A3，边距按中文公文规范

    统一文档解析¶

    提供跨 23 种文件格式的统一解析服务，同时用于文件预览和 LLM 上下文注入：

    • Office 文档：PDF / DOCX / DOC / ODT / PPTX / PPT / ODP / XLSX / XLS / ODS
    • 标记语言：Markdown（提取 Mermaid 图、表格、代码块、标题大纲）/ HTML
    • 数据文件：CSV / JSON / XML / YAML / ENV / LOG / SQL / INI / TOML / HTACCESS
    • 脚本文本：SH / BASH / TXT / RTF

    📂 文件管理¶

    • 工作区文件浏览器：树形文件结构，右键菜单支持创建、重命名、删除操作
    • 文本文件编辑器：内置编辑器，支持未保存更改检测、Ctrl+S 保存、切换文件前确认
    • 预览模式：Markdown 与 HTML 文件即时渲染预览
    • 文件变更跟踪：文件修改以 diff 对比展示，支持回滚、接受变更
    • 打开方式：用系统程序打开、在文件管理器中定位、HTML 在浏览器中打开、另存为下载

    🧠 记忆系统¶

    • 长期记忆：Agent 自动记录重要信息（项目事实、用户偏好、发现的问题等），跨会话持久化
    • 用户画像：维护用户画像文件，记录用户偏好、技能、需求
    • 项目知识：维护项目记忆文件，累积项目相关的决策和环境信息
    • 经验学习：自改进经验教训（正确做法/错误做法对照），Agent 从每次交互中积累经验
    • 记忆管理界面：记忆页可直接查看、编辑、新建记忆文件，经验页可浏览经验规则与历史记录

    ⏰ 定时任务¶

    • Cron 调度：支持标准 5 字段 cron 表达式
    • 任务管理：查看调度、下次运行时间、最近状态；新建、删除定时任务
    • 前端面板：定时任务页可视化查看和管理所有定时任务

    🔌 多渠道消息集成¶

    MiqroForge 具备多渠道消息中枢能力，可通过统一的消息渠道抽象接入飞书、钉钉、Slack、Discord、Telegram、QQ、Email、MoChat 等平台，支持入站消息监听和出站回复，并可通过访问控制列表（ACL）限制消息来源。

    桌面端现状：设置 → 渠道页当前提供全局行为开关（流式进度、发送工具提示、队列通知）；飞书配置界面暂未开放（后端模块保留）。渠道能力主要在网关形态下使用。

    🧩 技能系统 (Skills)¶

    技能是 Agent 能力的模块化扩展，每个技能是一个包含 SKILL.md 的目录，遵循 OpenClaw 兼容格式。

    内置技能¶

    技能 用途
    docx OOXML 原生操作，注释支持，接受修订
    pdf PDF 表单填写、注释、边界框检查
    xlsx Excel 公式重算、数据恢复
    pptx-generator PPT 生成、编辑、设计系统
    github 通过 gh CLI 与 GitHub 交互
    cron 定时提醒和重复任务
    memory 记忆系统，短期 + 长期回顾
    paper-research 学术论文搜索、下载、翻译、总结
    feishu-report 飞书内容推送（文本/卡片/文档/日历/任务）
    summarize 总结 URL、文件和 YouTube 视频
    tmux 远程操控 tmux 会话
    weather 通过 wttr.in 和 Open-Meteo 获取天气
    workspace-cleanup 整理工作区目录
    skill-creator 创建新技能的向导
    slurm SLURM 集群作业提交和管理

    技能管理界面¶

    • 技能页：左侧技能列表、右侧详情查看；新建技能（名称 + 描述）、删除技能

    🔌 插件系统 (Plugins)¶

    • 插件格式：plugin.json 清单，可包含 MCP 服务器、技能、斜杠命令、生命周期钩子
    • 桌面端管理：插件页查看已安装插件（名称/版本/状态），一键启用/禁用、卸载
    • 安装方式：将插件放入全局插件目录（~/.miqi/plugins/）或工作区插件目录；后端保留从 Git 地址克隆安装的能力
    • 钩子系统：支持 pre_tool / post_tool / on_error 生命周期注入

    🌐 网络搜索¶

    • web_search：通过 Brave / SearXNG / Hybrid 搜索引擎检索互联网
    • web_fetch：抓取网页内容并提取正文，内置 SSRF 防护（阻止私有 IP 网段和元数据服务）
    • 配置入口：设置 → 网络工具，可配置搜索、抓取与论文工具的提供商和参数

    🎓 学术论文¶

    • paper_search：通过 arXiv API 搜索学术论文
    • paper_get：获取论文元数据（标题、作者、摘要、分类等）
    • paper_download：下载 PDF，自动检测付费墙

    🛡️ 安全与沙箱¶

    执行管道¶

    所有工具执行经过四阶段安全管道：

    审批 (ApprovalPolicy) → 沙箱选择 (SandboxPolicyEngine) → 执行 (ToolRegistry) → 重试 (指数退避)

    WSL2 + bwrap 沙箱¶

    • Windows 平台：通过 WSL2 隔离执行环境，bwrap 提供 per-session 容器化
    • 文件系统规则：LANDLOCK 文件系统级网络策略控制
    • 文件隔离：独立 tmpfs + bind mount，进程/PID/UTS/User 命名空间隔离
    • 流式 I/O：支持 stdin/stdout 流式交互
    • 自动清理：会话结束自动销毁沙箱，异常退出后重启自动清理
    • macOS 限制：bwrap 在 macOS 上不可用，沙箱能力暂不支持

    权限系统¶

    • 审批策略：AUTO（自动批准安全工具）/ ASK（每次确认）/ DENY（拒绝）
    • 危险命令检测：39 种危险命令模式自动触发审批
    • 审批绕过模式：五个独立开关——全部绕过、命令审批、文件写入审批、工具确认、网络审批
    • 白名单：常用命令可永久放行
    • 工作区隔离：文件操作默认限制在工作区目录内
    • 变更保护：写入前自动创建原始内容快照，支持回滚
    • 默认拒绝：deny-by-default 权限策略

    🔧 开发者工具¶

    工具 说明
    Shell 执行 在沙箱内执行 Shell 命令，支持流式 I/O
    代码补丁 Unified Diff 多文件多 hunk 补丁应用，集成版本快照
    进程管理 进程生成、终止、列出、快照
    Git 集成 通过 github skill 调用 gh CLI（PR、Issue、Review 等）
    SLURM 高性能计算集群作业管理

    🤖 多模型提供商¶

    支持多家 LLM 提供商，带故障转移和负载均衡：

    • Anthropic（Claude 系列）
    • OpenAI（GPT 系列）
    • Google Gemini
    • OpenRouter（聚合平台）
    • DeepSeek
    • 可扩展的 Provider 接口，支持添加自定义提供商

    通过设置 → 模型标签页可视化管理提供商、API Key、接口地址与默认模型。

    📊 计划与任务追踪¶

    • PlanTracker：步骤状态管理（pending → in_progress → completed → skipped），计划页实时更新
    • 任务追踪：task_begin / task_end 覆盖自动生成的追踪名称，设置目标和父哈希实现跨会话血缘追踪

    💬 会话管理¶

    • 任务板：侧边栏会话列表按状态过滤——全部 / 进行中 / 待审阅 / 已完成，带计数角标
    • 新建与切换：新建会话（空会话自动复用）、点击切换会话、无限滚动加载
    • 状态流转：右键标记进行中/待处理/待审阅/已完成、重置状态
    • 归档与恢复：归档不需要的会话，在设置 → 归档标签恢复或永久删除
    • 批量操作：全选删除、全选归档
    • 旧版会话认领：旧版本创建的会话可一键迁移到当前版本
    • 详情浏览：会话页双栏查看消息记录（用户/助手/工具消息分样式展示）
    • 复制标识：复制会话标识便于排查

    🔗 MCP 协议集成¶

    通过 Model Context Protocol 接入外部工具服务器：

    • 动态加载 MCP 工具，自动注册到工具注册表
    • 进度心跳：长时任务定期报告进度
    • 超时控制：每个 MCP 工具可独立设置超时
    • 连接复用：MCP 进程保持存活，避免重复启动
    • 前端管理：MCP 页可视化管理服务器（命令行/远程地址、工具超时），支持网关模式按需激活工具

    🖥️ 设置向导与隐私确认¶

    首次启动自动进入隐私协议确认门与三阶段设置引导：

    隐私协议确认 → 环境检测 → WSL2 配置（仅 Windows） → LLM 提供商配置 → 开始使用
    • 隐私协议同意状态本地持久化；协议版本更新后老用户重新确认
    • 自动检测运行环境（打包版本直接使用内置运行时，无需额外安装）
    • Windows 下自动检测并引导安装 WSL2 沙箱发行版
    • 非 Windows 系统自动跳过 WSL2 步骤
    • 完成后可随时从设置 → 通用重新打开向导
